# Dhaka-Smart-Routing-Engine
# Dhaka Routing System - Complete Solution

Complete implementation of Dhaka Mini Map routing system using Dijkstra's algorithm.
Solves all 6 problems with proper modular structure.


## File Structure
- main.c - Program entry, solves all 6 problems
- graph.c - Graph operations  
- parser.c - CSV parsing
- dijkstra.c - Path finding algorithms
- scheduler.c - Time scheduling
- output.c - Output formatting
- utils.c - Utility functions

## Problems Solved
1. Shortest car route (distance)
2. Cheapest route (car + metro)
3. Cheapest route (all modes)
4. Cheapest with time scheduling
5. Fastest route
6. Cheapest with deadline
